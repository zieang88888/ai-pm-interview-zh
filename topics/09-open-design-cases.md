# 09 开放设计题与案例

> 面试压轴：给你一个场景，看你 10 分钟内能不能从 0 到 1 设计出可落地的 AI 产品。

### Q1 【基础】开放设计题的通用答题框架是什么？

- **答题框架**：
  1. 澄清需求：目标用户是谁、场景是什么、成功标准是什么（先问清楚再设计）。
  2. 拆解任务：用户要完成什么任务，哪些环节能用 AI 增强。
  3. 方案设计：AI 能力选型、功能流程、关键交互、兜底设计。
  4. 落地路径：MVP 范围、数据来源、迭代计划。
  5. 商业化/指标：怎么衡量成功、怎么赚钱。
  6. 加分项：主动点出风险与边界。
- **追问点**：你设计的产品最大的风险是什么？

### Q2 【实战】设计一个"AI 面试助手"，服务求职者。

- **答题框架**：
  1. 用户与场景：求职者准备面试，痛点是不知考什么、答不好、没反馈。
  2. 功能：AI 模拟面试官提问（按岗位定制）→ 用户作答 → AI 点评（内容/表达/改进）。
  3. 技术：LLM 生成问题与点评 + 岗位知识库（RAG）+ 语音交互。
  4. 差异化：不是"题库"，是"实战模拟 + 个性化反馈"。
  5. 指标：模拟次数、点评满意度、用户面试通过率（长期）。
  6. 商业化：免费基础题库 + 付费模拟与深度点评。
- **追问点**：怎么保证点评质量不变成"正确的废话"？

### Q3 【实战】设计一个"企业会议纪要 + 待办提取"的 AI 产品。

- **答题框架**：
  1. 用户：开会的人/管理者，痛点是纪要耗时、待办易漏。
  2. 功能：录音/上传 → 转写 → 智能纪要（结论/决议/待办）→ 自动分发到任务系统。
  3. 技术：ASR 转写 + LLM 结构化提取 + 任务系统集成。
  4. 关键设计：准确性兜底（人工可编辑）、权限（纪要只对参会人可见）。
  5. 指标：纪要生成耗时、待办提取准确率、分发成功率。
  6. 商业化：按席位订阅，集成飞书/钉钉/企微。
- **追问点**：多人说话分不清谁说的，产品怎么处理？

### Q4 【实战】设计一个"AI 内容审核"系统（面向 UGC 平台）。

- **答题框架**：
  1. 用户：平台运营，痛点是人审慢、漏审、成本高。
  2. 功能：文本/图片/视频自动审核（涉黄/暴力/广告/违规）→ 分级处置（通过/人工/拦截）。
  3. 技术：多模态模型 + 规则引擎 + 风险库，人机协同。
  4. 关键设计：误杀率与漏判率的平衡（宁可人工复核不可误伤）。
  5. 指标：拦截率、误杀率、审核时效、人工复审率。
  6. 合规：涉未成年人内容最高优先级。
- **追问点**：模型判"违规"但用户申诉，流程怎么设计？

### Q5 【实战】设计一个"AI 编程助手"产品（to 开发者）。

- **答题框架**：
  1. 用户：开发者，痛点是写样板代码、查 API、修 bug 耗时。
  2. 功能：代码补全、对话改码、错误解释、代码审查。
  3. 技术：代码大模型 + 项目上下文 + 规则系统。
  4. 差异化：准确性与隐私（代码不出境可自部署）。
  5. 指标：补全接受率、任务完成率、开发者留存。
  6. 商业化：免费基础 + 订阅高级；企业版私有部署。
- **追问点**：开发者最看重什么？为什么留存比付费更重要？

### Q6 【实战】设计一个"AI 客服"产品（替换/增强人工客服）。

- **答题框架**：
  1. 用户：企业与终端用户，痛点是响应慢、重复问题多。
  2. 功能：自动问答（FAQ/知识库）+ 意图识别转人工 + 工单创建。
  3. 技术：RAG 知识库 + 意图分类 + 兜底转人工（关键）。
  4. 关键设计：解决率 vs 满意度平衡，转人工门槛别太高。
  5. 指标：自助解决率、满意度、平均响应时间、转人工率。
  6. 商业化：按坐席/按调用量，企业私有化部署。
- **追问点**：用户情绪激动（骂人），AI 怎么应对？

### Q7 【实战】设计一个"AI 学习助手"（面向学生）。

- **答题框架**：
  1. 用户：学生，痛点是没人讲题、学习没规划。
  2. 功能：拍照/文字提问讲解、错题本、学习计划生成。
  3. 技术：多模态理解 + LLM 讲解 + 知识图谱/题库。
  4. 差异化：讲"思路"不喂"答案"（防作弊 + 真提升）。
  5. 指标：讲题满意度、错题掌握率、留存。
  6. 商业化：订阅制，家长付费；学校端 B 端。
- **追问点**：怎么防止学生拿 AI 直接抄答案？

### Q8 【实战】设计一个"AI 文档助手"（企业知识库问答）。

- **答题框架**：
  1. 用户：企业员工，痛点是制度/流程找不到、问人没人答。
  2. 功能：对话问答 + 引用溯源 + 权限控制 + 数据统计。
  3. 技术：RAG + 权限过滤 + 引用高亮。
  4. 关键设计：权限（谁能问什么）、无答案时明确说"不知道"。
  5. 指标：答准率、引用率、员工搜索时长下降。
  6. 商业化：按席位订阅，嵌入飞书/钉钉/企业微信。
- **追问点**：文档更新了，知识库怎么保持同步？

### Q9 【实战】设计一个"AI 营销文案生成器"。

- **答题框架**：
  1. 用户：运营/电商卖家，痛点是写文案慢、没灵感、转化差。
  2. 功能：输入商品/卖点 → 生成多版本文案（标题/详情/社媒）→ 风格/长度可调。
  3. 技术：LLM + 商品知识 + 品牌风格库（Few-shot）。
  4. 差异化：不是"通用文案"，是"懂你商品的文案"（结构化卖点输入）。
  5. 指标：生成采纳率、使用后转化提升、付费转化。
  6. 商业化：按量/订阅；电商平台插件。
- **追问点**：文案同质化（大家都用 AI 写）怎么破？

### Q10 【实战】面对一个全新场景（面试官指定），你的即兴设计思路？

- **答题框架**：
  1. 先花 1 分钟澄清：用户、任务、场景、成功标准。
  2. 找"AI 不可替代的价值点"：是省时、是规模化、还是新体验。
  3. 给 MVP：最小可用的功能切面，别铺太大。
  4. 给失败兜底：AI 答错/做错时怎么办。
  5. 给指标与商业化：怎么算赢、怎么赚钱。
  6. 全程边说边梳理，展示结构化思维。
- **追问点**：如果我说这个场景不需要 AI，你怎么反驳？
