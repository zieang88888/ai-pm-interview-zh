# 01 AI 行业与基础认知

> 开场必问：你对 AI 行业怎么看。考的是视野与判断，不是背概念。

### Q1 【基础】你怎么看待当前 AI 行业的发展阶段？

- **答题框架**：
  1. 结论先行：从"技术驱动"进入"应用落地"阶段，模型能力趋于同质化，竞争转向场景、数据与工程化。
  2. 论据：大模型基座能力成熟（长上下文/多模态/Agent），开源模型拉平门槛，成本持续下降。
  3. 判断：未来 2-3 年核心机会在垂直场景的深度落地与数据飞轮，而不是再卷一个基座。
  4. 落地视角：作为 PM，重点看"哪些场景的 ROI 跑得正"。
- **追问点**：你觉得哪些行业 AI 落地最快？为什么？

### Q2 【基础】什么是 AI、机器学习、深度学习、大模型？关系是什么？

- **答题框架**：
  1. AI 是让机器模拟人类智能的总称。
  2. 机器学习是实现 AI 的主流方法：从数据中学习规律。
  3. 深度学习是机器学习的分支：用多层神经网络自动提取特征。
  4. 大模型是深度学习的最新形态：海量参数 + 海量数据 + 自监督预训练，具备通用能力。
  5. 一句话串起来：AI ⊃ 机器学习 ⊃ 深度学习 ⊃ 大模型。
- **追问点**：大模型和传统深度学习模型本质区别是什么？

### Q3 【基础】大模型为什么"大"？参数多和模型能力强是什么关系？

- **答题框架**：
  1. 大在参数量（千亿级）与训练数据量（万亿 token）。
  2. 参数多 → 记忆与表达能力更强；数据多 → 覆盖知识与规律更广。
  3. 出现"涌现能力"：小模型没有、大模型突然具备的能力（如推理、遵循指令）。
  4. 但参数不是唯一：数据质量、架构、训练方法同样关键；边际收益递减。
- **追问点**：涌现能力怎么验证？对小模型有什么启发？

### Q4 【基础】当前主流大模型有哪些？各自特点？

- **答题框架**：
  1. 国际：OpenAI GPT 系列（通用对话/推理）、Anthropic Claude（长文/代码/安全）、Google Gemini（多模态）。
  2. 国内：DeepSeek（开源/性价比）、通义千问、文心一言、豆包、智谱 GLM、Kimi（长文本）。
  3. 分类维度：开源 vs 闭源、通用 vs 垂直、文本 vs 多模态。
  4. 选择逻辑：按任务类型、成本、数据合规、生态成熟度选型。
- **追问点**：开源模型和闭源模型各适合什么场景？

### Q5 【基础】什么是 AIGC？有哪些典型应用？

- **答题框架**：
  1. AIGC：用 AI 自动生成内容（文本/图片/音频/视频/代码）。
  2. 典型应用：智能写作、AI 绘画、AI 配音/音乐、数字人、AI 编程、营销素材生成。
  3. 商业价值：内容生产成本大幅下降，个性化内容规模量产。
  4. 挑战：内容质量不稳定、版权风险、合规审查。
- **追问点**：AIGC 内容的版权问题你怎么看？

### Q6 【进阶】什么是大模型的"幻觉"？产生原因？

- **答题框架**：
  1. 定义：模型生成看似合理但事实错误/编造的内容。
  2. 原因：本质是"预测下一个词"，没有事实校验；训练数据覆盖不足或冲突；解码时追求流畅性优先于准确性。
  3. 表现：编造引用、张冠李戴、自信地答错。
  4. PM 视角：幻觉不可完全消除，只能缓解（RAG、约束输出、置信度提示、人工兜底）。
- **追问点**：幻觉率怎么测？哪些场景幻觉是致命的？

### Q7 【进阶】什么是 Agent？和"聊天机器人"有什么本质区别？

- **答题框架**：
  1. Agent：能自主规划、调用工具、多步执行、根据反馈自我修正的 AI 系统。
  2. 区别：聊天机器人"你问它答"，Agent"你给目标它干活"；Agent 有记忆、有工具、有行动闭环。
  3. 核心组成：LLM（大脑）+ 工具调用（手脚）+ 规划/反思（策略）+ 记忆（上下文）。
  4. 商业意义：从"信息助手"升级为"数字员工"，可承担完整工作流。
- **追问点**：Agent 落地的最大瓶颈是什么？

### Q8 【进阶】大模型、AI 应用、AI 产品三者什么关系？

- **答题框架**：
  1. 大模型是能力底座（发动机）。
  2. AI 应用是调用底座能力解决具体任务的软件（车）。
  3. AI 产品是应用 + 用户价值 + 商业模式 + 体验设计的完整形态（能上路赚钱的车）。
  4. PM 的职责：把"能力"翻译成"用户价值"，把"演示"做成"可持续的产品"。
- **追问点**：一个"AI 功能"和"AI 产品"的区别？

### Q9 【进阶】你怎么理解"数据飞轮"？在 AI 产品中怎么转起来？

- **答题框架**：
  1. 定义：用户使用 → 产生数据 → 数据改进模型/体验 → 体验提升 → 更多用户使用的正向循环。
  2. 前提：能采集到高质量、可标注、可反馈的数据闭环。
  3. 产品设计：埋点反馈机制（赞踩、纠错、修正）、人工标注流程、A/B 验证。
  4. 风险：数据隐私合规、反馈偏差（只有不满意的用户才反馈）。
- **追问点**：没有数据飞轮条件的初创产品怎么办？

### Q10 【进阶】AI 行业未来 3 年你最看好什么方向？

- **答题框架**：
  1. 给结论：看好 Agent 工作流（企业自动化）+ 垂直领域深度模型 + AI 原生产品形态。
  2. 逻辑：模型能力同质化后，壁垒在场景理解、数据与落地工程。
  3. 个人视角：结合自己背景（做过 XX 领域）谈匹配度，体现真诚。
  4. 反差点：顺带提一两个"短期过热、可能回落"的方向，显得有独立判断。
- **追问点**：你为什么不去追现在最热的 XX 方向？
