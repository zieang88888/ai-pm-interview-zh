# 04 AI 产品设计与落地

> 产品经理的本行：怎么把 AI 能力做成用户愿意用、用得爽、留得住的产品。

### Q1 【基础】AI 产品设计与传统产品设计有什么不同？

- **答题框架**：
  1. 能力不确定性：传统功能结果确定，AI 输出有概率性——要设计"失败路径"。
  2. 体验交互：从"点击"变为"对话/生成"，要设计引导、确认、修正机制。
  3. 评估体系：从"功能正确"到"效果质量 + 成本 + 风险"多维度。
  4. 迭代方式：Prompt/模型/数据持续迭代，产品是"养"出来的。
- **追问点**：你最认同哪一点？举例说明。

### Q2 【基础】你怎么判断一个需求"该不该用 AI"？

- **答题框架**：
  1. 先看问题真伪：用户真的需要吗？频率/规模够吗？
  2. 再看任务适配度：模式识别/生成/理解类适合 AI；确定性计算、强规则类不一定。
  3. 算经济账：错误代价、延迟、成本 vs 收益。
  4. 给反例：能用规则解决的硬上 AI = 增加不确定性与成本。
- **追问点**：举个例子说明一个"不该用 AI"的场景？

### Q3 【基础】设计一个 AI 功能的完整流程是什么？

- **答题框架**：
  1. 需求分析：用户任务、场景、痛点、现有解法。
  2. 方案设计：AI 能力选型（模型/技术路线）、交互设计、兜底设计。
  3. 效果定义：量化指标（准确率、满意度、降本数字）。
  4. 验证迭代：小流量实验、评测集、A/B、上线监控。
  5. 持续优化：数据回流、Prompt 迭代、模型升级。
- **追问点**：哪个环节最容易翻车？

### Q4 【进阶】AI 产品的"失败体验"怎么设计？

- **答题框架**：
  1. 承认失败：不假装成功，明确告知"没识别出来/不确定"。
  2. 给修正路径：重新输入、点选纠错、转人工。
  3. 分级处理：低风险场景容忍失败（推荐），高风险场景强制确认（医疗/金融）。
  4. 收集反馈：把失败变成数据，反哺模型与产品。
- **追问点**：高置信度但答错的场景，你的兜底方案是什么？

### Q5 【进阶】怎么判断一个 AI 产品有没有"产品力"（PMF）？

- **答题框架**：
  1. 留存与复购：用户用了一次还想不想用（DAU/WAU、次留）。
  2. 核心任务完成率：任务成功率、用户主动纠错比例。
  3. 口碑与自传播：NPS、分享率、邀请率。
  4. 商业信号：付费转化、续费率、客单价。
  5. 对比基准：跟"没有 AI 的旧方案"比，价值是否显著。
- **追问点**：AI 功能留存差，先查技术还是先查体验？

### Q6 【进阶】AI 产品的冷启动怎么破？

- **答题框架**：
  1. 先人工后智能（Wizard of Oz）：人工模拟 AI 提供服务，验证需求再上模型。
  2. 小切口：选一个高频、低风险、效果容易感知的场景先做深。
  3. 数据积累：冷启动阶段重点不是模型效果，是"数据闭环 + 用户反馈"。
  4. 差异化：找大模型直接给不了的体验（垂直数据、工作流集成、服务闭环）。
- **追问点**：人工模拟的成本和风险怎么控制？

### Q7 【进阶】多模态能力在你的产品里怎么用？

- **答题框架**：
  1. 先列用户任务：哪些环节有"图/音/视频"信息需要理解或生成。
  2. 举例：电商（商品图理解/生成）、文档（扫描件 OCR）、社交（内容生成）。
  3. 评估：多模态的准确率、成本、延迟是否满足场景。
  4. 落地顺序：先做"理解类"（识别/提取）再上"生成类"（创作），风险递进。
- **追问点**：文生图内容审核怎么做？

### Q8 【进阶】怎么做 AI 产品的用户研究？

- **答题框架**：
  1. 传统方法照用：访谈、问卷、可用性测试——观察用户与 AI 的真实交互。
  2. AI 特有方法：Prompt 日志分析（用户怎么问）、失败案例复盘、纠错行为分析。
  3. 期望管理研究：用户对"AI 会犯错"的接受度与信任建立。
  4. 数据洞察：用"任务完成率 + 满意度 + 求助率"组合判断体验。
- **追问点**：用户问得"怪"（Prompt 写不清），是产品问题还是用户问题？

### Q9 【实战】给你一个场景（如"企业知识库问答"），你会怎么做产品？

- **答题框架**：
  1. 需求拆解：目标用户（员工）、核心任务（找答案）、痛点（找不到/不及时）。
  2. 方案：RAG + 权限控制 + 引用溯源 + 兜底（无答案明确说）。
  3. 指标：答案准确率、引用可溯率、平均解决时间、满意度。
  4. 迭代：先接高频文档（制度/FAQ），数据回流优化切块与 Prompt。
  5. 商业化：按席位/按调用量/嵌入现有办公系统。
- **追问点**：如果文档权限很复杂，你怎么设计？

### Q10 【实战】AI 产品怎么定价？说下思路。

- **答题框架**：
  1. 成本结构：token/GPU 成本随用量变化——先算边际成本。
  2. 定价模式：按量付费、订阅制、混合（基础订阅 + 用量包）。
  3. 价值锚定：对比用户替代方案（人工成本/旧工具）定价值，而不是按成本加价。
  4. 风险：用户滥用（刷量）→ 设用量上限；效果不稳定 → 退款/补偿机制。
- **追问点**：按量付费和订阅制各有什么利弊？
