# 05 模型评估与指标

> 不会评估 AI 效果的 PM 不是好 PM：怎么测、测什么、怎么证明"变好了"。

### Q1 【基础】AI 产品的效果怎么量化评估？

- **答题框架**：
  1. 定任务指标：任务成功率、答案准确率、推荐命中率等核心指标。
  2. 加质量指标：忠实度（是否忠于依据）、完整性、格式合规、幻觉率。
  3. 加体验指标：满意度（CSAT）、完成时间、纠错率、求助率。
  4. 加业务指标：转化、留存、降本、人效。
  5. 原则：核心指标 + 护栏指标组合，防止单一指标优化过头。
- **追问点**：准确率和用户满意度不一致时，以哪个为准？

### Q2 【基础】什么是"幻觉率"？怎么测？

- **答题框架**：
  1. 定义：生成内容与事实/依据不符的比例。
  2. 测量：构建带标准答案的评测集 → 逐条比对 → 统计事实错误占比。
  3. 细分：无中生有、张冠李戴、过时信息、错误引用。
  4. 自动化：LLM-as-judge 初筛 + 人工抽检复核。
- **追问点**：幻觉率 5% 能不能上线？取决于什么？

### Q3 【基础】什么是 LLM-as-judge？靠谱吗？

- **答题框架**：
  1. 定义：用大模型当"裁判"，给生成结果打分/对比（如谁答得更好）。
  2. 优点：成本低、速度快、可规模化。
  3. 缺点：裁判本身有偏见（偏好长答案/特定风格）、可能自评过高。
  4. 正确用法：judge 评分 + 人工抽检校准，定标准答案集对齐。
- **追问点**：judge 和人工评分不一致怎么处理？

### Q4 【进阶】怎么搭建 AI 产品的评测集？

- **答题框架**：
  1. 来源：真实用户请求采样（脱敏）+ 专家构造的边界/极端案例。
  2. 分层：核心任务用例 + 长尾用例 + 风险用例（安全/隐私/涉黄涉政）。
  3. 标注：多人标注 + 仲裁机制，给标准答案或评分标准。
  4. 维护：随功能迭代增删用例，防止"过拟合评测集"。
  5. 规模：从几十条起步，核心场景几百条够用。
- **追问点**：评测集会不会"背题"？怎么防？

### Q5 【进阶】A/B 测试在 AI 产品里怎么做？有什么特殊点？

- **答题框架**：
  1. 分流：用户级/请求级分流，保证同质。
  2. 组别：基线（旧模型/规则）vs 实验（新模型/Prompt），可多版本并行。
  3. 特殊点：AI 输出不稳定 → 需要更大样本与更长周期；同用户多次体验会"习惯化"，注意新鲜度效应。
  4. 指标：核心指标 + 成本指标（token 消耗）一起看。
  5. 风险：模型更新期间结果漂移，要冻结版本跑实验。
- **追问点**：新模型效果指标提升但成本翻倍，怎么决策？

### Q6 【进阶】线上监控 AI 效果怎么做？

- **答题框架**：
  1. 实时监控：成功率、延迟、错误率、token 消耗、限流。
  2. 质量监控：抽样评估输出质量（自动化 + 人工抽检）、幻觉举报。
  3. 业务监控：转化/留存/满意度联动。
  4. 预警机制：指标突降告警、模型供应商故障切换。
  5. 反馈闭环：用户纠错/举报回流 → 定期复盘。
- **追问点**：线上效果突然变差，排查顺序是什么？

### Q7 【进阶】"效果不错但业务没增长"怎么分析？

- **答题框架**：
  1. 先验"效果"定义：准确率高 ≠ 用户感知好 ≠ 业务价值高。
  2. 拆漏斗：曝光→试用→留存→付费，找断点。
  3. 可能原因：功能价值低（用户用一次就走）、入口浅、期望管理差、定价问题。
  4. 结论：AI 效果是必要条件不是充分条件，回到产品价值本身。
- **追问点**：怎么证明"是 AI 功能带来的增长"？

### Q8 【进阶】怎么比较两个模型（如换模型选型）？

- **答题框架**：
  1. 建评测集：同一批用例，双模型跑，打分对比。
  2. 维度：效果（准确率/质量分）+ 成本（token 单价/用量）+ 延迟 + 稳定性。
  3. 场景化加权：不同场景权重不同（客服重准确、创作重风格）。
  4. 灰度验证：小流量线上对比，看真实指标。
  5. 别忘了工程成本：迁移成本、API 兼容、供应商风险。
- **追问点**：开源模型和闭源模型你会怎么选？

### Q9 【进阶】如何衡量"AI 真的帮用户省了时间"？

- **答题框架**：
  1. 直接指标：任务完成时长（对比无 AI 基线）、一次完成率、操作步数。
  2. 间接指标：用户主动纠错率（越低越省心）、回访率。
  3. 对照法：同任务"用 AI vs 不用 AI"分组计时。
  4. 用户感知：NPS 中"帮我节省时间"细项。
- **追问点**：AI 让任务更快但用户不觉得，问题出在哪？

### Q10 【实战】给你的产品设计一套"AI 效果驾驶舱"，包含哪些指标？

- **答题框架**：
  1. 使用层：调用量、活跃用户、人均次数。
  2. 质量层：任务成功率、幻觉率、满意度、纠错率。
  3. 成本层：token 消耗、单次成本、成本/收入比。
  4. 业务层：转化、留存、客诉率。
  5. 分层联动：一眼看出"哪个环节拖后腿"。
- **追问点**：驾驶舱最重要的三个指标你选什么？为什么？
