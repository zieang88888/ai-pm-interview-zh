# 07 商业化与成本

> 社招/高级岗的分水岭：AI 不只会"炫"，还得会"算账"。

### Q1 【基础】AI 产品的成本由哪些构成？

- **答题框架**：
  1. 推理成本：token 费用（输入+输出）、GPU/API 调用——随用量线性增长。
  2. 开发成本：模型选型、Prompt 调优、RAG 基建、工程开发。
  3. 数据成本：采集、清洗、标注、存储。
  4. 运营成本：人工兜底、审核、客服。
  5. 结论：AI 产品是"高边际成本"产品，成本结构必须算清。
- **追问点**：单次对话的成本怎么估算？

### Q2 【基础】怎么估算一次 AI 调用的成本？

- **答题框架**：
  1. 输入 token：Prompt（系统+用户+上下文）长度 × 输入单价。
  2. 输出 token：模型生成长度 × 输出单价。
  3. 加 RAG：检索的向量化、存储、调用次数。
  4. 加兜底：失败重试、人工介入比例。
  5. 示例估算：一次客服问答 1-2k token，成本约几分到几毛钱（视模型）。
- **追问点**：输出 token 为什么比输入贵？

### Q3 【基础】AI 产品怎么定价？主流模式有哪些？

- **答题框架**：
  1. 订阅制：按月/年收费，适合高频使用（Copilot 类）。
  2. 按量付费：按调用/token/次数收费，适合低频或 B 端。
  3. 混合：基础订阅 + 用量包，兼顾稳定收入与弹性。
  4. 增值分层：免费基础 + 付费高级模型/无限额度。
  5. 定价依据：用户价值（省了多少人力/时间）而非成本。
- **追问点**：免费版和付费版的功能怎么切？

### Q4 【进阶】AI 产品的"成本黑洞"有哪些？怎么防？

- **答题框架**：
  1. 长上下文滥用：用户狂发长文档、无限多轮对话 → 设上下文上限与摘要。
  2. 重试风暴：失败自动重试多次 → 限次重试。
  3. 恶意刷量：脚本批量调用 → 限流、配额、风控。
  4. 低价值高频：简单问题也用最强模型 → 模型分级路由。
  5. 对策：成本监控看板 + 用量告警 + 分级限流。
- **追问点**：模型分级路由怎么设计？

### Q5 【进阶】免费用户和付费用户的成本怎么平衡？

- **答题框架**：
  1. 免费版用小模型/慢速队列/低配额，控制边际成本。
  2. 付费版解锁强模型/快速/高配额。
  3. 让"免费体验"足以种草（价值感知），但不足以白嫖（成本可控）。
  4. 指标：免费转付费率、免费用户单次成本、付费用户 LTV。
- **追问点**：免费版配额给多少合适？依据是什么？

### Q6 【进阶】怎么证明 AI 功能的商业价值（ROI）？

- **答题框架**：
  1. 降本：替代人力（人工客服、内容生产）的工时 × 成本。
  2. 增效：任务完成时间缩短、吞吐量提升。
  3. 增收：转化率、客单价、复购提升。
  4. 体验：NPS、投诉率（间接价值）。
  5. 论证方式：对照组实验 + 财务折算，老板看得懂的账。
- **追问点**：价值是"算出来的"还是"感受出来的"，怎么取舍？

### Q7 【进阶】AI 产品怎么避免"叫好不叫座"（有口碑没收入）？

- **答题框架**：
  1. 诊断：免费用户多但付费少 → 价值不够刚性/付费点模糊。
  2. 对策：找到"不可替代场景"（没它用户就得人工干），把付费点焊死。
  3. 定价验证：访谈 + 定价测试，别拍脑袋。
  4. 渠道：To B 走销售+实施，To C 走增长+裂变。
  5. 耐心：AI 产品商业化周期长，先保留存再做收入。
- **追问点**：如果竞品免费，你怎么卖？

### Q8 【进阶】B 端 AI 产品（To B）的商业化有什么特殊点？

- **答题框架**：
  1. 决策链长：采购、IT、业务方、老板多方决策——要做价值共识。
  2. 定制化成本：私有化部署、数据迁移、流程集成。
  3. 定价模式：按席位/按调用/项目制/订阅，B 端偏好可预测成本。
  4. 标杆案例：先做标杆客户出效果，再复制。
  5. 合同风险：效果承诺要留余地（AI 不保证 100%）。
- **追问点**：B 端客户要求"效果不好退款"，你怎么设计条款？

### Q9 【进阶】开源模型和商业 API 的成本对比怎么算？

- **答题框架**：
  1. 商业 API：按 token 付费，无前期投入，但单价高、数据出境。
  2. 开源自部署：算力成本（GPU）+ 运维成本 + 数据不出境。
  3. 盈亏平衡：调用量大到一定程度，自部署更划算（百万级调用/天量级）。
  4. 隐性成本：自部署的工程维护、版本升级、故障责任。
  5. 结论：起步用 API，规模后评估自部署/混合。
- **追问点**：数据敏感场景（如医疗/政务）怎么选？

### Q10 【实战】你的产品要上线一个"AI 助手"，怎么算投入产出？

- **答题框架**：
  1. 成本侧：开发成本（一次性）+ 推理成本（随用量）+ 运营兜底成本。
  2. 收入/价值侧：替代人工、提升转化、留存提升的量化估计。
  3. 平衡点：月调用量达到多少时回本。
  4. 风险预留：效果不达预期的止损线（如 3 个月指标未达标即调整）。
  5. 结论：给出"建议先做还是不做"的判断。
- **追问点**：如果老板说"先做了再说"，你怎么管理预期？
